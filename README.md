## 📌 About The Project

The **E-Commerce Website** is a frontend web development project designed to provide a modern online shopping experience.

The project contains multiple pages that represent the main sections of an e-commerce platform.

Users can navigate between:

- 🏠 Home
- 🛍️ Products
- 🛒 Cart
- 💳 Checkout
- 👤 User Profile

This project also demonstrates a professional **Git and GitHub team collaboration workflow**, including:

- GitHub Issues
- Feature Branches
- Commits
- Pushes
- Pull Requests
- Code Reviews
- Requested Changes
- Approvals
- Merging
